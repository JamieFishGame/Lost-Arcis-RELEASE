Hello! I'm Jamie M, and this is the demo to Lost Arcis.

Lost Arcis is a puzzle metroidvania with a retro asthetic. The gameplay is based around exploration and puzzle solving, with a focus on cyphers. The language of the game is not known at first, but it can be decyphered through exploration of the Arcis.

Lost Arcis has been under development for around a year at the time of this demo releasing (Update: closer to two years now!), although for the majoirty of it's development it went by the name "Currently Unnamed Maze Game." As this is a demo to the game, more is planned to be added for the full release.

STATE OF THE GAME: As of September 8th 2026, Lost Arcis is playable from start to end! There are many features left to add at this point, many revolving around accessibility and sound design. I will also surely make some changes to the game's routing as I receive feedback from playtesters. That said, it is (practically at least) possible to complete the game on the current build.

Full Windows and Linux builds are available as .zip files in their respective folders. Windows builds should include a .exe and a .pck file, while Linux builds should include a .x86_64, .sh, and .pck file. 

Releases are organized by date, so picking the most recent is recommended.

Thank you for trying Lost Arcis! Feedback is much appreicated.
